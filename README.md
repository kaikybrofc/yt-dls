# yt-dls

Projeto para download de mídia do YouTube.

## Sobre

Este repositório reúne o código e as ferramentas do `yt-dls`. Consulte os arquivos do projeto para verificar os formatos suportados, os requisitos e os comandos disponíveis na versão atual.

## Começando

```bash
git clone https://github.com/kaikybrofc/yt-dls.git
cd yt-dls
```

Em seguida, instale as dependências indicadas pelos arquivos de configuração do projeto e use os scripts ou comandos documentados no código.

## Uso responsável

Use a ferramenta somente em conteúdos que você possui, tem autorização para baixar ou que estejam disponíveis para download nos termos aplicáveis. Respeite os direitos autorais e os termos de serviço das plataformas.
